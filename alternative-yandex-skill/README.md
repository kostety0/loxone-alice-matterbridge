# Loxone → Алиса (свой навык умного дома)

Небольшой сервер на Python. Он получает команды от умного дома Яндекса и передаёт их
Miniserver'у по домашней сети через HTTP API Loxone. Облако Loxone и сторонние сервисы не нужны.

```
Станция → облако Яндекса → HTTPS-туннель → этот сервер (ваш ПК) → Miniserver (LAN)
```

Что поддерживается:

| В Loxone | В Алисе | Команды |
|---|---|---|
| Switch (в т.ч. внутри Lighting Controller) | свет / розетка | вкл/выкл |
| Dimmer, EIBDimmer | свет | вкл/выкл, яркость, «ярче/темнее» |
| Jalousie | шторы | открыть/закрыть, «открой на 30%» |

## 1. Пользователь в Loxone Config

Создайте отдельного пользователя (например, `alice`) с доступом к нужным блокам и
загрузите конфигурацию в Miniserver. Лучше использовать пароль из латиницы и цифр.

## 2. Установка на ПК

1. Установите Python 3.11 или новее с python.org. При установке отметьте «Add Python to PATH».
2. Распакуйте папку `loxone-alice`, например в `C:\loxone-alice`.
3. В командной строке выполните:
   ```
   cd C:\loxone-alice
   pip install -r requirements.txt
   ```
4. Скопируйте `config.example.toml` в `config.toml` и заполните его: IP Miniserver'а, логин и пароль Loxone,
   `client_secret` (длинная случайная строка) и `password` (пароль, который вы один раз
   введёте при привязке).
5. Проверьте, что мост видит Miniserver:
   ```
   python server.py config.toml --list
   ```
   Должен появиться список устройств с комнатами и текущими значениями. Если каких-то
   устройств там быть не должно, перечислите их в `exclude`. Если нужны только
   некоторые, перечислите их в `include`.

## 3. Публичный HTTPS-адрес (без белого IP)

Яндексу нужен постоянный HTTPS-адрес, который ведёт на `localhost:8090`.
Подойдёт любой туннель с **постоянным** адресом. Например, tuna.am (российский сервис):

1. Зарегистрируйтесь и установите клиент `tuna`. На бесплатном тарифе сессия
   ограничена по времени, поэтому для постоянной работы нужен платный тариф.
2. Запустите туннель на своём постоянном поддомене:
   ```
   tuna http 8090 --subdomain=ВАШ-ПОДДОМЕН
   ```
   Адрес будет вида `https://ВАШ-ПОДДОМЕН.ru.tuna.am`.
3. Проверка: откройте в браузере `https://ВАШ-ПОДДОМЕН.ru.tuna.am/v1.0`, должно показаться `ok`.

Есть и другие варианты: fxTunnel, Cloudflare Tunnel (нужен свой домен) или дешёвый VPS
с `ssh -R`.

## 4. Навык в Яндекс Диалогах

1. Откройте https://dialogs.yandex.ru/developer → «Создать навык» → **Умный дом**.
2. Заполните поля:
   - **Название:** любое, например «Мой Loxone».
   - **Backend → Endpoint URL:** `https://ВАШ-ПОДДОМЕН.ru.tuna.am`, без `/v1.0` на конце.
   - **Доступ:** Приватный.
   - **Связка аккаунтов** (кнопка «Создать» в разделе авторизации):
     - Идентификатор приложения: `client_id` из config.toml (`loxone-alice`)
     - Секрет приложения: `client_secret` из config.toml
     - URL авторизации: `https://ВАШ-ПОДДОМЕН.ru.tuna.am/oauth/authorize`
     - URL для получения токена: `https://ВАШ-ПОДДОМЕН.ru.tuna.am/oauth/token`
     - URL для обновления токена: `https://ВАШ-ПОДДОМЕН.ru.tuna.am/oauth/token`
3. Сохраните и нажмите «Опубликовать». Приватный навык проходит проверку быстро.

## 5. Подключение в «Дом с Алисой»

1. Удалите старые устройства SmartPort: откройте навык → «Отвязать».
2. Нажмите «+» → «Устройство умного дома» и найдите свой навык в разделе «Мои навыки».
3. Нажмите «Привязать к Яндексу». Откроется страница моста, введите `password` из config.toml.
4. Нажмите «Обновить список устройств». Устройства появятся в нужных комнатах.

## 6. Автозапуск на Windows

Мост и туннель должны работать постоянно. Самый простой способ: положите `start.bat`
в папку автозагрузки (`Win+R` → `shell:startup`). Можно вместо этого создать задачу в
«Планировщике заданий» с запуском при входе в систему.
Важно, чтобы ПК не уходил в сон: «Параметры → Система → Питание → Сон: Никогда».

## Если что-то не работает

- `python server.py config.toml --debug` выводит подробный лог.
- Пишет «401 неверный логин или пароль»: проверьте пользователя Loxone и загрузите
  конфигурацию в Miniserver.
- Алиса отвечает «устройство не отвечает»: проверьте, что запущены и мост, и туннель
  (адрес `/v1.0` должен отвечать `ok`).
